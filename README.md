# Bluepage Secure

Bluepage's lockdown app. When a teacher sets a Bluepage writing session to Lockdown, students write it here: the site in one locked window.

**Download:** [Windows](https://github.com/cookie6-hub/bluepage-secure/releases/latest/download/Bluepage-Secure-Setup.exe). The Mac version is coming.

Open the file you downloaded. If Windows says it protected your PC, choose **More info**, then **Run anyway**. Bluepage Secure opens when it's installed.

Questions: ask your teacher, or see [usebluepage.com](https://usebluepage.com).
